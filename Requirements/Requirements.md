# Flight Booking Application – Requirement Understanding

## 1. Application Overview
The Flight Booking application is a web-based practice application that allows users to search for flights by selecting departure and destination cities, travel dates, passenger count, and travel class. Users can review available flights, select a flight, enter passenger details, complete the payment step, and receive booking confirmation.

## 2. Testing Objective
The objective of this project is to verify that the flight booking workflow behaves as expected, handles valid and invalid user input correctly, provides appropriate validation and navigation, and allows a user to complete a booking successfully. The project also aims to identify, document, and communicate reproducible defects.

## 3. In Scope

- Departure and destination selection
- Departure and return dates
- One-way and round-trip flow
- Passenger count

- Flight results
- Sorting and filtering
- Flight selection
- Passenger details
- Input validation
- Payment form
- Booking confirmation
- Navigation between booking stages
- Positive, negative, boundary, exploratory, and end-to-end testing

## 4. Out of Scope

- Real banking/payment processing
- Actual money transactions
- Real email delivery

- Production infrastructure testing
