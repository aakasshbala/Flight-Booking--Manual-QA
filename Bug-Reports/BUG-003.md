\# BUG-003 – Payment accepts an invalid CVV



\## Environment

\- Browser: Google Chrome

\- OS: Windows

\- Application: Flight Booking Practice

\- Test Case: TC021



\## Preconditions

User has reached the payment page after selecting a flight and entering passenger details.



\## Steps to Reproduce

1\. Navigate to the payment page.

2\. Enter an invalid/short CVV such as `12`.

3\. Enter valid values in the other required payment fields.

4\. Submit the payment.



\## Test Data

CVV: `12`



\## Expected Result

The application should reject the invalid CVV and display an appropriate validation message.



\## Actual Result

The application accepted the invalid CVV and allowed the booking to proceed to confirmation.



\## Severity

Medium



\## Priority

High
