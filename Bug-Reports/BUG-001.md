# BUG-001 – Payment accepts an invalid/short card number

## Environment
- Browser: Google Chrome
- OS: Windows
- Application: Flight Booking Practice
- Test Case: TC019

## Preconditions
User has reached the payment page after selecting a flight and entering passenger details.

## Steps to Reproduce
1. Navigate to the payment page.
2. Enter `03` in the card number field.
3. Enter valid values in the other required payment fields.
4. Submit the payment.

## Test Data
Card Number: `03`

## Expected Result
The application should reject the invalid/short card number and display an appropriate validation message.

## Actual Result
The application accepted the short card number.
