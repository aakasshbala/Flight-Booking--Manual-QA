\# BUG-002 – Payment accepts an expired card expiry date



\## Environment

\- Browser: Google Chrome

\- OS: Windows

\- Application: Flight Booking Practice

\- Test Case: TC020



\## Preconditions

User has reached the payment page after selecting a flight and entering passenger details.



\## Steps to Reproduce

1\. Navigate to the payment page.

2\. Enter an expired expiry date such as `01/2020`.

3\. Enter valid values in the other required payment fields.

4\. Submit the payment.



\## Test Data

Expiry Date: `01/2020`



\## Expected Result

The application should reject the expired expiry date and display an appropriate validation message.



\## Actual Result

The application accepted the expired expiry date and allowed the booking to proceed to confirmation.
