# Flight Booking Application – Manual QA Project

## Overview
A portfolio-focused manual QA project covering a multi-step flight booking web application.

## Workflow
Flight Search → Flight Selection → Passenger Details → Payment → Booking Confirmation

## Testing Activities
- Requirement understanding
- Test scenario design
- Test case design
- Positive and negative testing
- Boundary Value Analysis
- Equivalence Partitioning
- Decision Table Testing
- Exploratory Testing
- End-to-End Testing
- Defect reporting
- Test execution
- Test summary reporting

- Requirements
- Test Scenarios

- Test Data
- Defect Reports
- Evidence
- Test Summary

## Application
QA Practice – Flight Booking Automation Practice

> This project is a manual QA exercise performed against a publicly available practice application. Results are based on actual execution and are not intended to represent production airline testing.
